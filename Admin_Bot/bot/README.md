# 🛡️ Admin Guard Bot

Мощный Telegram бот для администрирования чатов и каналов.

## 📋 Функции (20+)

### ⚖️ Модерация
| Команда | Описание |
|---------|----------|
| `/ban` | Забанить пользователя (@user или реплай) |
| `/unban` | Разбанить пользователя |
| `/mute` | Замутить (@user 1h/1d/1w) |
| `/unmute` | Размутить пользователя |
| `/kick` | Кикнуть пользователя |
| `/warn` | Выдать предупреждение |
| `/unwarn` | Снять предупреждение |
| `/del` | Удалить сообщение (реплай) |
| `/purge` | Удалить последние N сообщений |

### ⚙️ Настройки
| Команда | Описание |
|---------|----------|
| `/rules` | Показать правила |
| `/setrules` | Установить правила |
| `/pin` | Закрепить сообщение |
| `/unpin` | Открепить сообщение |
| `/unpinall` | Открепить все |
| `/slowmode` | Медленный режим (0-60 сек) |
| `/setwelcome` | Установить приветствие |
| `/welcomeoff` | Выключить приветствие |

### 🤖 Автоматизация
| Команда | Описание |
|---------|----------|
| `/antispam` | Антиспам (on/off) |
| `/antiflood` | Антифлуд (число сообщений) |
| `/addfilter` | Добавить слово в фильтр |
| `/delfilter` | Удалить из фильтра |
| `/filters` | Список фильтров |
| `/addreply` | Добавить автоответ |
| `/delreply` | Удалить автоответ |
| `/replies` | Список автоответов |
| `/captcha` | Капча для новичков (on/off) |

### 📊 Информация
| Команда | Описание |
|---------|----------|
| `/stats` | Статистика чата |
| `/info` | Инфо о пользователе |
| `/admins` | Список админов |
| `/id` | ID чата/пользователя |
| `/logs` | История действий |

### 🔧 Прочее
| Команда | Описание |
|---------|----------|
| `/report` | Жалоба на сообщение |
| `/promote` | Повысить до модератора |
| `/demote` | Снять права модератора |
| `/settings` | Открыть настройки |
| `/help` | Список команд |

Панель Mini App лежит в каталоге **`../web/`** (см. [DEPLOY.md](../DEPLOY.md)).

## 🚀 Установка

### 1. Клонирование
```bash
git clone <repo>
cd <repo>/bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка
Установите переменные окружения:
```bash
export BOT_TOKEN="ваш_токен_от_BotFather"
export WEBAPP_URL="https://ваш-домен.com"
```

### 4. Запуск
```bash
python bot.py
```

## ⏱️ Форматы времени

| Формат | Значение |
|--------|----------|
| `10s` | 10 секунд |
| `10m` | 10 минут |
| `1h` | 1 час |
| `1d` | 1 день |
| `1w` | 1 неделя |

## 📝 Переменные приветствия

| Переменная | Значение |
|------------|----------|
| `{user}` | Имя пользователя |
| `{username}` | @username |
| `{chat}` | Название чата |
| `{count}` | Количество участников |
| `{id}` | ID пользователя |

**Пример:**
```
/setwelcome 👋 Привет, {user}! Ты {count}-й участник чата {chat}!
```
